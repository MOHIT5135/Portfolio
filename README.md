## 🚀 Built With

* **HTML5** &mdash; Semantic structure and layout
* **CSS3** &mdash; Custom styling, grid layouts, and smooth animations
* **JavaScript (ES6+)** &mdash; Mobile menu toggle and dynamic text animations (Typed.js)
* **Formspree** &mdash; Serverless contact form handling

## 🌟 Key Features

* **Fully Responsive Design:** Optimized for mobile devices, tablets, and large desktop viewports with custom media queries.
* **Interactive Hero Section:** Features a dynamic typing animation cycling through key developer roles.
* **Smooth Scrolling Navigation:** Built with native CSS scroll behavior for seamless transitions across sections.
* **Integrated Contact Form:** Allows recruiters and visitors to send direct messages straight to my inbox via Formspree without page redirects.
